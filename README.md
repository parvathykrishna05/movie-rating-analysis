# Movie Rating Analysis Project
*A Case Study using the MovieLens Dataset*

This folder contains the complete project source code for the movie rating analysis.

## Project Structure
- `analysis.py`: The main Python script that processes the data, calculates the top movies, and generates visual graphs.
- `requirements.txt`: Required Python libraries.
- `ratings.csv` & `movies.csv`: The MovieLens dataset files.

## Instructions to Run

1. **Install dependencies**:
   Make sure you have Python installed. Open your terminal in this folder and run:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Analysis**:
   Execute the analysis script by running:
   ```bash
   python analysis.py
   ```

3. **Check the Output**:
   - High-quality visualization graphs will be automatically saved in a new folder named `plots/`.
   - A CSV file named `top_rated_movies_report.csv` will be generated containing the fully ranked list of movies.
